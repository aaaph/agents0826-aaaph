# AI Agents PRO — практика потоку 08.2026

Наскрізний кейс курсу: **один запит клієнта проходить усі модулі**,
кожен модуль додає рівно один шар архітектури — і різниця в поведінці
агента виникає сама, її не треба інсценувати.

> «Посилка EE123456789UA не прийшла вже два тижні. Я хочу повернути гроші за доставку.»

## Як користуватись

Кожна тека `moduleN/` — самодостатній стан проєкту «на кінець свого
модуля». Наступна = попередня + один шар, тож `diff module3 module4`
показує рівно те, що додає заняття. Історія комітів цього репозиторію —
та сама прогресія.

```bash
cd module1
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # впишіть свій ANTHROPIC_API_KEY
python run.py
```

Ключ читається **тільки з `.env`** — у коді його немає, `.env` у `.gitignore`.

## Мапа модулів

| Тека | Модуль курсу | Додається | «Вау-момент» |
|---|---|---|---|
| `module1/` | Основи агентів | цикл + один інструмент | агент чесно каже, що не може оформити повернення |
| `module2/` | RAG / Agentic RAG | база правил у контексті | цитує «Правило 4.2» замість вигадувати |
| `module3/` | Фреймворки і Agent SDK | стани + чекпоінт → LangGraph → create_agent | процес убили — агент продовжив з місця зупинки |
| `module4/` | MAS + Context Engineering | роутер + право діяти | вперше створено претензію CLM-00001 |
| `module5/` | Протоколи MCP / A2A | інструменти через MCP-сервер | той самий бекенд працює і в Claude Code |
| `module6/` | Безпека і Guardrails | guardrails + хуки + атаки | injection у даних → block → оператор |
| `module7/` | Observability + Evaluation | eval-датасет + гейт | тиха деградація: скор падає, логи чисті |
| `module8/` | Продакшн, деплой, AIOps | FastAPI + Docker + SLO + стрімінг | та сама логіка — інший спосіб запуску |

## Головний важіль

`CAPABILITIES` у `domain/backend.py`: на модулях 1–2 агент може тільки
подивитись статус, на модулі 3 — дізнатись право (але не діяти), і лише
з модуля 4 з'являється `create_claim`. Саме тому та сама фраза клієнта
на М1 отримує чесну відмову, а на М4 вперше доводиться до результату.

## Під свій домен (вайбатон)

Замініть чотири місця — і кейс перестає бути навчальним:
`config.py → USER_QUERY` · `domain/backend.py → ORDERS` ·
`domain/knowledge.py → KB` · `data/evalset.json`.
